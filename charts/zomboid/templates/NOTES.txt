3. Find the address players connect to:
{{- if eq .Values.service.type "LoadBalancer" }}

     -o jsonpath='{.status.loadBalancer.ingress[0].ip}'
   Connect in-game via Join -> IP: <that IP>, Port: {{ .Values.service.gamePort }}
   (UDP {{ .Values.service.gamePort }} and {{ .Values.service.udpPort }} must both be reachable)
{{- else if eq .Values.service.type "NodePort" }}

{{- else }}
   Service type is ClusterIP — reachable only inside the cluster.
